# Učebné materiály – TUKE FEI

Lokálna webová knižnica študijných materiálov. Aktuálne sú v nej predmety OS (Operačné systémy) a USaA. Predmet OS obsahuje šesť materiálov získaných z dodaných PDF dokumentov, zoradených podľa čísla v názve súboru.

## Spustenie

1. Rozbaľte ZIP archív.
2. Otvorte `index.html` v modernom webovom prehliadači.
3. V časti OS vyberte materiál. Vyhľadávanie prehľadáva názvy, opisy aj text dokumentov.

Web funguje lokálne a nevyžaduje server ani internetové pripojenie. Obsah PDF bol prevedený na text a HTML; pôvodné obrázky a grafické rozloženie PDF sa nereprodukujú, text a dostupné ukážky kódu sú zachované. Pri zložitých tabuľkách alebo skenovaných častiach môže byť potrebná ručná kontrola.
